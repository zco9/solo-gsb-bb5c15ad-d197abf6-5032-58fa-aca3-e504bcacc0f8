# WebVTT 字幕时序修复器

一款**完全本地运行**的 WebVTT（`.vtt`）字幕时序修复工具。粘贴或导入字幕后，可以直接在时间轴上拖动片段及其边界，修复重叠、间隔过小、时长不足等问题。锁定片段不会被任何调整推动；当约束无解时，本次调整会被自动撤销，并在时间轴上标出冲突区间。

内置**两点同步批量校准**：选择两个按时间排序的未锁定锚点片段并分别输入新开始时间，由唯一线性映射整体校准闭区间内的全部未锁定片段；应用前时间轴以虚影预览并显示影响数量，存在冲突时禁止应用并完整列出，绝不部分写入。

内置**画面布局预览**：解析所选片段的 `line` / `position` / `size` / `align` 设置，在 16:9 预览区中显示字幕框与 10% 安全区；非法取值或字幕框超出安全区会进入问题清单，点击即可定位片段。四个布局字段提供独立编辑控件，修改时其它未知 cue 设置的原始顺序与内容完全保留。

内置**合并双语轨**：以当前字幕为主轨，粘贴或选择另一份 WebVTT 作为副轨；仅把时间交集占较短片段时长 ≥50% 的主副片段列为候选，再计算保持双方顺序、每条片段最多使用一次、总交集时长最大的配对（总分并列时依次选择副轨索引序列字典序更小的方案）。解析后只预览不改数据；确认后仅把配对副轨文本作为新一行追加到主轨，主轨时间、标识符、设置与锁定状态原样保留，未配对副轨不写入。

内置**片段摘录导出**：输入原时间轴上的起止时间，实时预览命中的 cue 数量与裁剪后的时间码，再下载一份独立 WebVTT。仅纳入与左闭右开区间有正时长交集的 cue（仅端点相接不纳入），各 cue 起止裁到交集后统一减去摘录起点；cue 文本中的 WebVTT 时间戳标签只保留落在裁剪后 cue 内部的标签并按同一偏移改写，普通内联标签、文字、标识符、设置与文件头原样保留。无命中或时间范围无效时说明原因并禁止下载；整个过程当前编辑内容不变。

内置**智能分行**：对当前未锁定字幕批量生成不超过两行的换行建议。行宽按可见字素计算（中文及全角字符计 2，其余计 1；WebVTT 内联标签与时间戳标签不计宽且不可拆开）；可设置每行最大宽度，算法在空格、标点或字素边界选择断点并优先减少两行宽差，闭合标点不会出现在行首、开放标点不会出现在行尾；需要超过两行或单字素超宽时逐条标出无解原因。预览原文、建议文本与无解项后，确认仅增删可行字幕的换行，其余字符、标签、时间戳、时间码与 cue 设置原样保留，可直接再导出 WebVTT。

内置**术语统一**：在右侧面板输入多组原词与替换词，对未锁定 cue 的正文生成批量替换预览。匹配以可见文字为准，允许原词跨越 `<b>`、`<v …>` 等 WebVTT 内联格式标签，但 `<00:01.500>` 时间戳标签与换行作为匹配边界；替换时保留所有标签原文、顺序及标签外未命中的文字。同一位置多条规则命中时取最长原词，等长按输入顺序，且基于原文一次匹配（替换结果不再参与匹配）。预览逐条显示命中次数（含每条规则的细分计数）与替换后的正文；确认后只写入命中的未锁定 cue，时间码、标识符、cue 设置与锁定状态不变，仍可正常导出 WebVTT。

内置**说话人标注迁移**：粘贴「起点、终点、角色名」三列表（从电子表格粘贴按 Tab 分列，也支持逗号或空格分隔，首行可为表头），对每条未锁定字幕按时间区间汇总各角色的重叠总时长，自动选重叠最长的角色；仅端点接触不计重叠，同名角色的多个区间时长合并。无任何重叠的片段跳过；最长重叠并列时列为**歧义**并等待手工选择。预览分三组显示原角色、候选角色（含各自重叠秒数）与跳过原因，可逐条改选其它候选或排除（跳过区可恢复）。确认后只把单一说话人的字幕正文**包入或更新最外层 WebVTT `<v 角色名>` 标签**：已有一个包住整个正文的 `<v>` 标签时只更新开标签中的角色名（保留类名与标签位置），否则在整个正文外层包一层新标签；其它内联标签、`<00:01.500>` 时间戳标签与换行逐字符保留。正文已含多个说话人片段（多个 `<v>` 开标签）时不自动覆盖，直接列入跳过。表内容或字幕变化时预览实时重算，写入后可直接「导出 WebVTT」。

技术栈：**React 18 + TypeScript + Vite**，纯前端，无后端，数据不离开浏览器。

## 一条命令启动（Docker Compose）

```bash
docker compose up --build
```

启动后用浏览器访问：

> **http://localhost:8080**

停止：`Ctrl+C`；后台运行：`docker compose up --build -d`；停止并移除容器：`docker compose down`。

如 8080 端口被占用，修改 `docker-compose.yml` 中的 `"8080:80"`（例如 `"9090:80"`）即可。

## 本地开发（无需 Docker）

```bash
npm install
npm run dev        # 开发服务器，访问 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建
npm test           # 运行核心逻辑测试（求解器/解析器/同步/双语合并/摘录导出/智能分行/术语统一/说话人迁移，无需浏览器）
```

## 使用方法

1. **导入字幕**：点击右上角「粘贴 / 导入」，选择 `.vtt` 文件，或直接粘贴 WebVTT 文本后「解析并载入」。首次打开会自动载入一份带问题的示例字幕。
2. **在时间轴上调整**：
   - 拖动片段**中部**：整体平移（保持时长）；
   - 拖动片段**左/右边缘**：修改开始/结束时间（改变时长）；
   - 滚轮区域上方有「－ / ＋ / 适应窗口」可缩放时间轴，也可横向滚动。
3. **锁定片段**：点击列表中的 🔓，或在右侧检查器勾选「锁定」。锁定片段在任何拖动传播中**绝不移动或改变时长**。
4. **约束设置**（右侧栏）：
   - **最小片段时长**：任何片段（含被传播压缩的片段）不得短于该值；
   - **相邻片段间隔**：相邻片段之间至少保留的间隔。
5. **冲突传播规则**：
   - 向右拖动时，压力按操作方向**向右传播**：后续片段先整体平移，撞到锁定片段时再从近到远收缩到最小时长；
   - 向左拖动为镜像过程，边界为锁定片段或时间轴起点 `00:00.000`；
   - 传播后仍无法满足全部约束时，调整**自动撤销**，红色斜纹标出冲突区间，并在时间轴下方显示原因横幅；
   - 再次开始拖动或手动编辑后，冲突标记自动清除，也可点击「消除标记」。
6. **实时反馈**：
   - 时间轴上红色斜纹 = 重叠/非法时间（错误），黄色虚线斜纹 = 间隔不足/时长不足（警告）；
   - 右侧「问题清单」列出全部问题（含布局问题），点击任一问题会选中并滚动到对应片段；
   - 悬停片段可在底部查看精确时间码与时长，拖动时有跟随的时间提示。
7. **两点同步（批量校准）**（启动后访问 **http://localhost:8080**，在右侧「两点同步」面板操作）：
   - 在下拉框中按时间顺序选择两个**未锁定**的锚点片段（锚点 1 需早于锚点 2，锁定片段不会出现在可选项中），并分别输入它们的新开始时间；
   - 由两个锚点的旧、新开始时间确定唯一线性映射 `t′ = k·t + b`，将闭区间 [锚点 1, 锚点 2] 内所有**未锁定**片段的 start/end 一并变换；区间外片段与锁定片段保持不变；
   - 输入的同时，时间轴即以**虚影**（蓝色虚线框，与原片段同泳道）预览校准结果，面板同步显示映射参数与**影响数量**；
   - 出现以下任一情况时「应用校准」被禁用并**列出全部冲突片段**（点击可定位到对应片段），不会部分写入：
     - 新锚点顺序无效（锚点 2 的新开始时间未晚于锚点 1），或锚点本身顺序/状态无效；
     - 变换后任一片段时长低于当前「最小片段时长」，或开始时间早于 `00:00.000`；
     - 校准后区间内及两侧边界的相邻片段不满足当前「相邻片段间隔」。
   - 点击「应用校准」后一次性写入全部结果；「重置」清空锚点选择与输入。
8. **画面布局预览与编辑**：
   - 右侧「画面布局预览」按 16:9 画面显示所选片段的字幕框，并叠加四边各 10% 的安全区（绿色虚线框）；
   - 字幕框位置由 `line` / `position` / `size` / `align` 决定，缺省值遵循 WebVTT 规范（position 50%、size 100%、贴底、居中）；`size` 未显式设置时按估算文本宽度（默认字号 5% 屏高）显示实际占位；
   - 检查器中提供四个布局字段的**独立编辑控件**（`line`/`position`/`size` 文本框、`align` 下拉框），留空即移除该设置；修改这四个字段时，其它未知 cue 设置（如 `vertical:rl`）的原始顺序与内容完全保留；
   - 非法取值（如 `align:middle`、`size:120%`）或字幕框超出 10% 安全区时，会以**警告**形式进入问题清单，点击即可定位到对应片段；只有显式设置了 `line`/`position`/`size` 的片段才做安全区判定；
   - 布局问题不影响导出，仍可按当前内容导出。
9. **合并双语轨**（右侧「合并双语轨」面板）：
   - 以当前字幕为**主轨**，点击「选择 / 粘贴副轨 WebVTT」，选择 `.vtt` 文件或直接粘贴另一份 WebVTT 文本后「解析并预览配对」；解析仅用于预览，**不会改动任何数据**；
   - 只有时间交集占**较短片段时长 ≥ 50%**（恰好 50% 计入）的主副片段才列为候选，仅端点接触（交集为 0）不计；
   - 候选之上求**保持双方顺序、每条片段最多使用一次、总交集时长最大**的配对（带权 LCS 动态规划）；总分并列时，依次选择**副轨索引序列字典序更小**的方案；
   - 预览逐条列出每条主轨：时间码、锁定标记、主轨文本、配对副轨文本（含副轨序号与交集时长），未配对主轨标注“文本保持不变”；另**单列未配对副轨**（确认后不会写入）；点击任一行可定位到对应主轨片段；
   - 「确认合并」后，仅把每条配对副轨文本**作为新一行追加**到主轨文本之后（主轨多行文本原样保留），主轨时间、标识符、cue 设置与锁定状态完全不变；未配对主轨/副轨均不写入；
   - 「重新选择副轨」回到输入步骤；「取消」关闭面板且不改动数据。合并后继续使用「导出 WebVTT」即可得到双语字幕。
10. **片段摘录导出**（右侧「片段摘录导出」面板）：
    - 点击「设置摘录区间并预览」，输入原时间轴上的**摘录起点 / 终点**（左闭右开 `[起点, 终点)`），输入的同时即时预览；
    - 仅与区间有**正时长交集**的 cue 被纳入（仅端点相接不计），命中列表逐条给出**裁剪后时间码**（统一减去摘录起点，从 `00:00.000` 开始）、原时间码与是否裁剪左右边界；
    - cue 文本中的 WebVTT **时间戳标签**（如 `<00:01.500>`）只保留落在裁剪后 cue 内部的标签并按同一偏移改写；恰好落在裁剪右端点的标签不保留；普通内联标签（`<b>`、`<v …>` 等）、文字、cue 标识符、cue 设置与文件头原样保留；
    - 时间范围无效（结束不晚于开始、起点早于 `00:00.000`）或区间内无命中时，面板说明原因并**禁止下载**；
    - 点击「下载摘录 WebVTT」下载独立文件，复用标准导出的序列化与浏览器下载；**当前编辑内容不会被改动**，文件头（NOTE/STYLE/REGION）原样写回。
11. **智能分行**（右侧「智能分行」面板）：
    - 点击「生成换行建议」，设置**每行最大宽度**（按可见字素计：中文及全角字符计 2，其余计 1；WebVTT 内联标签与时间戳标签不计宽且不可拆开）；
    - 仅对**未锁定**片段生成不超过两行的建议：断点选在空格、标点或字素边界，优先让两行宽差最小；闭合标点不会出现在行首，开放标点不会出现在行尾；断点处的空格保留在原行尾，不删除任何字符；
    - 已满足「≤2 行且每行不超宽」的片段保持原样；需要超过两行、单字素超宽或标点禁则导致无合法断点时，在「无解」列表中逐条标出原因，这些片段保持原文；
    - 预览逐条给出原文与建议（含两行各自宽度），点击可定位到对应片段；「确认应用」仅增删可行片段的换行，其余字符、标签、时间戳、时间码与 cue 设置原样保留，之后可正常「导出 WebVTT」。
12. **术语统一**（右侧「术语统一」面板，启动后访问 **http://localhost:8080**）：
    - 点击「设置替换规则并预览」，在规则表中逐行输入**原词 → 替换词**（替换词留空表示删除原词），可用「+ 增加规则」添加多组；重复原词仅最先输入的一条生效（面板会标出）；
    - 匹配以**可见文字**为准、按字素簇精确匹配（区分大小写）：原词允许跨越 `<b>`、`<i>`、`<v …>` 等内联格式标签（标签不计入可见文字），但**时间戳标签** `<00:01.500>` 与换行符是匹配边界，原词不得跨越；
    - 同一位置多条规则同时命中时取**最长原词**，等长按**输入顺序**取最先者；基于原文**一次匹配**，替换后的文字不再参与匹配，相邻命中互不重叠；
    - 替换保留全部标签原文与出现顺序：命中范围之外的标签与未命中文字留在原位，夹在命中字素之间的标签按相对缝隙放入替换词（替换词较短时贴在替换词末尾）；
    - 面板顶部汇总命中片段数、命中总次数、未命中与锁定跳过数量；下方**逐条预览**仅列出有命中的未锁定 cue：时间码、命中次数（按规则细分）、原文与替换后正文，点击可定位到对应片段；
    - 点击「确认写入」后**只写入命中的未锁定 cue** 的正文；时间码、标识符、cue 设置与锁定状态完全不变，无命中与锁定片段保持原样；之后仍可「导出 WebVTT」。「取消」关闭面板且不改动数据。
13. **说话人标注迁移**（右侧「说话人标注迁移」面板，启动后访问 **http://localhost:8080**）：
    - 点击「粘贴角色区间表并预览」，在文本框粘贴三列表：每行 **起点、终点、角色名**。从 Excel / Google 表格粘贴时按 Tab 分列；也可用英文/中文逗号或空格分隔（空格分隔时第 3 列起拼回，允许带空格的名字）；第一行若为「起点 终点 角色名」之类表头会自动跳过；时间码支持 `MM:SS.mmm` 与 `HH:MM:SS.mmm`；无法解析的行列在面板顶部标出并忽略；
    - 对每条**未锁定**字幕，按与表中各时间区间的**重叠总时长**汇总角色（仅端点接触不计；同名角色的多个区间时长相加），选重叠最长的角色；候选按重叠秒数降序展示；
    - 最长重叠并列时该条进入**歧义**组，在下拉框中手工选择角色（或排除）；未选择的歧义条不会写入；
    - 与表无任何重叠、已锁定、以及正文已含多个 `<v>` 说话人片段的条目进入**跳过**组并显示原因；正文预览逐条给出原角色（从现有 `<v>` 标签提取）、候选角色与重叠秒数、原文与写入结果；每条都可「改选」其它候选或「排除本条」（排除后可在跳过组「恢复自动选择」）；
    - 输入或字幕变化时预览实时重算；手工改选在重算后仍尽量保留（所选角色已不在候选中时回到自动结果）；
    - 点击「确认迁移」后，只对单一说话人的片段写入：已有一个包住整个正文的 `<v>`（或 `<v.类名>`）标签时**仅更新开标签中的角色名**，其它一切字符不动；否则在整个正文外层包一层 `<v 角色名>…</v>`，正文（含其它内联标签、时间戳标签、换行）逐字符保留；已是该角色标签的条目不重复写入；多说话人片段绝不自动覆盖。之后可直接「导出 WebVTT」。
14. **精确编辑**：选中片段后在右侧检查器手动输入时间码（支持 `MM:SS.mmm` 与 `HH:MM:SS.mmm`，逗号小数点亦可）、编辑多行文本、cue 设置（`line`/`position`/`align` 等）与标识符，可复制或删除片段。
15. **导出**：点击「导出 WebVTT」下载修复后的 `.vtt` 文件。导出内容为规范 WebVTT：
   - 字幕文本（含多行、内联标签如 `<b>`、时间戳标签）原样保留；
   - cue 设置与 cue 标识符原样保留；
   - 文件头中的 `NOTE` / `STYLE` / `REGION` 块原样写回；
   - 时间戳规范化为 `HH:MM:SS.mmm`（不足 1 小时为 `MM:SS.mmm`）；
   - 锁定状态仅属于编辑器状态，不会写入文件。

> 注意：右侧检查器中的手动时间码输入为**直接设置**（便于精确修正），不会触发跨片段传播；跨片段传播只在时间轴拖动时发生。手动编辑造成的重叠/间隔问题会立即出现在问题清单中，可再用拖动方式修复。
